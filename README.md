# Backspace — documents légaux

Les pages publiées ici sont la **politique de confidentialité** et les **conditions
générales d'utilisation** de l'application Android Backspace, dans les douze langues du
produit.

- [Politique de confidentialité](https://lunqolabs.github.io/backspace/confidentialite/)
- [Conditions générales d'utilisation](https://lunqolabs.github.io/backspace/conditions/)

Les deux adresses ci-dessus sont sans langue : elles redirigent vers celle du navigateur, et
proposent la liste des douze à qui n'exécute pas JavaScript. Ce sont elles que déclare la
fiche Google Play.

**La version française fait foi.** Les onze autres sont fournies pour information, et chaque
page traduite le dit en toutes lettres.

## Ce dépôt ne contient pas le code de l'application

Uniquement le site. Les documents sont écrits en Markdown dans le dépôt de développement, et
ces pages en sont **générées** : les modifier ici créerait une seconde vérité.
